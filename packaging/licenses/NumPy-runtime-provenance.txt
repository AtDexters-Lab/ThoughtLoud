NumPy 2.5.3 Linux CPython 3.12 wheel: embedded GCC runtime provenance

The wheel's license includes libgfortran (GPLv3 with the GCC runtime exception),
but the separately shipped library itself still needs corresponding source.
libquadmath is LGPL-2.1-or-later; its license is included alongside this note.

Both runtime libraries were matched to AlmaLinux 8.10 binary packages
8.5.0-28.el8_10.alma.1. Auditwheel renames libraries and changes ELF loader
metadata. The GNU build IDs and SHA-256 of the executable .text section match

The source RPM contains upstream source, patches and the RPM spec build recipe.
Extract it with rpm2cpio and cpio into a private directory, or rebuild it with
rpmbuild --rebuild in an AlmaLinux 8.10 build environment with its BuildRequires.
NumPy's sdist contains the wheel build scripts. Rebuild the wheel and application
to regenerate loader metadata for changed libraries; do not assume that copying
a differently named library will satisfy the wheel's recorded ELF dependencies.

The collector rejects changes to these wheel-library hashes rather than silently
reusing this source attribution for another NumPy wheel or architecture.
